🚀 Power BI Project –

YouTube Analytics Dashboard

 I built a Power BI dashboard to analyze YouTube user engagement, recommendation performance, watch behavior, and device/category insights. The goal was to understand how audiences interact with content and what drives viewing patterns.
 
📁 The dataset includes detailed user interaction metrics — watch time, engagement actions, device type, and timestamps — ideal for behavioral analysis.

📂 Dataset

The dataset contained detailed attributes:
- user_id – Unique identifier for each viewer
- category – All entries are “Tech”
- device – All entries are “Mobile”
- video_id – Unique identifier for each video
- video_duration – Total video length in seconds
- watch_time_of_day – Time of day when video was watched (e.g., Evening)
- watch_time – Actual duration watched in seconds
- watch_percent – Percentage of video watched (1.0 = 100%)
- liked, commented, subscribed_after, recommended, clicked – Binary flags for user interaction (all 0)
- Date & Time – Timestamp of interaction

🔑 Key Insights Included:

 - Overall engagement metrics – likes, comments, shares & subscriber growth
 - Recommendation effectiveness – CTR and impact of suggested videos
 - Watch time & viewing behavior – average duration, peak hours, binge patterns
 - Device & category insights – content preferences across mobile, desktop & smart TV
 - Trend analysis of viewing behavior over time
 - Audience segmentation by age group & content type
 - Dynamic slicers and measures for flexible exploration.

 🛠️ Power BI Skills Practiced
 
- Data Cleaning in Power Query (removing duplicates, handling binary flags)
- DAX Measures for engagement rate, watch ratio, and time slot analysis
- KPI Cards for Total Watch Time, Avg Watch %, and Engagement Count
- Conditional Formatting to highlight zero-engagement rows
- Slicers for Date, Time of Day, Device, and Category
- Custom Tooltips for user-level behavior
